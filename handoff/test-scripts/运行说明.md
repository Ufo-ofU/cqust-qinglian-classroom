# 本地测试脚本说明

这些是此前测试使用的脚本，作为复现起点提供，不会随网站部署。
只能用于本地测试；脚本中的服务地址固定为http://localhost:5173。
load.cjs会结束当前本地课堂并创建新课堂，写入4700份测试回答，请只对独立测试数据库运行。

安装测试工具（与产品依赖分开）：
在handoff/test-scripts目录运行 npm install playwright。
qa.cjs默认使用本机Microsoft Edge（channel: msedge）；未安装时可按Playwright支持方式安装Chromium并调整launch配置。

运行时工作目录为website：
1. 确保已按主文档启动网站并建立空的本地数据库。
2. mkdir work（若目录已存在则跳过）。
3. node ../handoff/test-scripts/qa.cjs .
4. node ../handoff/test-scripts/load.cjs .

qa.cjs假设登录后没有未结束的旧课堂；重复执行前应结束旧课堂并按需调整“创建课堂/创建新课堂”的UI定位。
截图和结果输出到当前工作目录work/。
这些脚本不代替生产环境测试，不要未经授权修改脚本向线上大量发请求。
